VanillaHack

A Minecraft client focused on competitive BedWars gameplay.

VanillaHack is a lightweight Minecraft client built with a focus on BedWars, PvP and a clean, modern experience.

Features

* Combat modules
* Movement utilities
* Visual modules
* Player utilities
* Miscellaneous tools
* Modern custom GUI
* Lightweight client-side architecture
* Modular API and event system

Status

VanillaHack is currently in active development.

The API and core systems are currently being developed. The GUI and gameplay modules are coming next.

Expect breaking changes while the project is under development.

Development

Requirements

* Java
* Minecraft
* Fabric Loader
* Gradle

Build

./gradlew build

On Windows:

gradlew.bat build

Direction

VanillaHack is primarily designed around BedWars gameplay rather than being a general-purpose vanilla utility client.

The goal is to keep the client fast, clean and focused while providing a modern user interface.
